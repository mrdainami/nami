# Shortcuts & gestures

Small moves that make your desk easier to use.

In Nami, click **Shortcuts** at the bottom right, open **Settings → Shortcuts**,
or choose **Help → Keyboard Shortcuts**. The reference works offline, and shows
the keys for the computer you are on.

## Open what your agent makes

Hold **Command (⌘)** on a Mac, or **Ctrl** on Windows, and click a link or file
path in a session. Web links open in your browser. Files open here in Nami.
Hover a link for a reminder, or right-click it for the available actions.

| Action | Mac | Windows |
| --- | --- | --- |
| Open a web link in your browser | ⌘ + click | Ctrl + click |
| Open a file in Nami | ⌘ + click | Ctrl + click |
| Reveal a file in Finder / File Explorer | ⌥⌘ + click | Ctrl+Alt + click |
| Reveal a folder in Finder / File Explorer | ⌘ + click | Ctrl + click |
| Open, copy, or reveal a link | Right-click | Right-click |

These gestures apply to session output. Links in a document's **Read** mode
open with a normal click. Missing file paths can still be copied from their
right-click menu; an open hint appears only when Nami can resolve the target.

## Everyday shortcuts

| Action | Mac | Windows |
| --- | --- | --- |
| New session | ⌘N | Ctrl+Shift+T |
| Open the agent picker | ⌘K | Ctrl+Shift+K |
| Open a folder | ⌘O | Ctrl+Shift+O |
| New window | ⇧⌘N | Ctrl+Shift+N |
| Open Settings | ⌘, | Ctrl+, |
| Save the active file | ⌘S | Ctrl+S |
| Close the active pane | ⌘W | Ctrl+Shift+W |
| Dismiss a dialog or leave an expanded pane | Esc | Esc |

On Windows the keys carry a Shift because a terminal needs the plain ones:
inside a session, Ctrl+N, Ctrl+K, Ctrl+O and Ctrl+W belong to the shell and to
the agent running in it. The Ctrl+Shift keys work everywhere, a session
included. Anywhere else — the sidebar, a file, an empty desk — the plain Ctrl
key works too. Ctrl+Shift+S also saves, for a preview open over a session.

## In a session on Windows

Copy and paste follow Windows Terminal, so that Ctrl+C can still stop a program.

| Action | Keys |
| --- | --- |
| Copy the selection | Ctrl+C with text selected, or Ctrl+Shift+C |
| Stop the running program | Ctrl+C with nothing selected |
| Paste | Ctrl+V, or Ctrl+Shift+V |
| Select everything in the session | Ctrl+Shift+A |

On a Mac these are ⌘C, ⌘V and ⌘A, and Ctrl+C always stops the program.

## Arrange your desk

| Action | Gesture |
| --- | --- |
| Reorder a pane | Drag its header |
| Resize a pane | Drag its resize handle |
| Reset a pane's size | Double-click its resize handle |
| Rename a session | Double-click its title |

## In the workspace

| Action | Mac | Windows | Where |
| --- | --- | --- | --- |
| Rename the selected file or folder | Return | Enter | Workspace list has focus |
| Move the selected item to Trash / the Recycle Bin | ⌘⌫ | Ctrl+Delete | Workspace list has focus |
| Add selected file content to a session | ⇧⌘Return | Ctrl+Shift+Enter | File selection toolbar |

**⌘** Command · **⌥** Option · **⇧** Shift

Shortcuts inside an agent's terminal can vary by agent. This reference covers
Nami's controls.
