# Shortcuts & gestures

Small moves that make your desk easier to use.

In Nami, click **⌘ Shortcuts** at the bottom right, open **Settings → Shortcuts**,
or choose **Help → Keyboard Shortcuts**. The reference works offline.

## Open what your agent makes

Hold **Command (⌘)** and click a link or file path in a session. Web links open
in your browser. Files open here in Nami. Hover a link for a reminder, or
right-click it for the available actions.

| Action | Gesture |
| --- | --- |
| Open a web link in your browser | ⌘ + click |
| Open a file in Nami | ⌘ + click |
| Reveal a file in Finder | ⌥⌘ + click |
| Reveal a folder in Finder | ⌘ + click |
| Open, copy, or reveal a link | Right-click |

These gestures apply to session output. Links in a document's **Read** mode
open with a normal click. Missing file paths can still be copied from their
right-click menu; an open hint appears only when Nami can resolve the target.

## Everyday shortcuts

| Action | Keys |
| --- | --- |
| New session | ⌘N |
| Open the agent picker | ⌘K |
| Open a folder | ⌘O |
| New window | ⇧⌘N |
| Open Settings | ⌘, |
| Save the active file | ⌘S |
| Close the active pane | ⌘W |
| Dismiss a dialog or leave an expanded pane | Esc |

## Arrange your desk

| Action | Gesture |
| --- | --- |
| Reorder a pane | Drag its header |
| Resize a pane | Drag its resize handle |
| Reset a pane's size | Double-click its resize handle |
| Rename a session | Double-click its title |

## In the workspace

| Action | Keys | Where |
| --- | --- | --- |
| Rename the selected file or folder | Return | Workspace list has focus |
| Move the selected item to Trash | ⌘⌫ | Workspace list has focus |
| Add selected file content to a session | ⇧⌘Return | File selection toolbar |

**⌘** Command · **⌥** Option · **⇧** Shift

Shortcuts inside an agent's terminal can vary by agent. This reference covers
Nami's controls.
